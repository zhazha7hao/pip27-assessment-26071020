# T0：A+B 测评流程示范

本题提供完整实现，用于展示：测评机如何编译题目源码、调用固定接口并检查结果。考生不需要补全本题。

## 题目要求

实现函数 `add`，返回两个整数的和。

```cpp
int add(int a, int b);
```

例如，`add(2, 3)` 返回 `5`，`add(-2, 3)` 返回 `1`。

测试数据保证 `a + b` 在 `int` 的可表示范围内，因此本题不考察整数溢出。

## 文件说明

- `include/ab.hpp`：声明固定接口。测评程序通过这个头文件知道如何调用函数。
- `src/ab.cpp`：提供 `add` 的完整示范实现。
- `README.md`：整道题的详细说明文档，请务必**仔细阅读**

题目源码中没有 `main()`。程序入口由 `testing/T0_ab/` 中的测评程序提供。

## 测评流程

1. `testing/T0_ab/` 中的 CMake 将 `src/` 下的 `.cpp` 编译。
2. CMake 将编译结果与测评程序链接，生成可执行文件。
3. 测评程序调用 `add(a, b)`。
4. 测评程序将返回值与预期答案比较，输出测试结果。

在仓库根目录运行公开测评示例：

```bash
bash testing/T0_ab/run.sh
```

`run.sh`、CMake 和测评程序的具体内容位于 `testing/T0_ab/`，不属于本题源码目录。
