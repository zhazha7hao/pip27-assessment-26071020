# T0：A+B

## 题目描述

给定两个整数 `a` 和 `b`，计算它们的和。

本题提供完整实现，是测评流程示范题。通过阅读题目源码和公开测评程序，可以了解后续题目如何被编译、调用和评分。

## 固定接口

题目使用 `include/ab.hpp` 中定义的 `Solver` 类：

```cpp
Solver solver(a, b);
int result = solver.sum();
```

构造函数接收两个整数。`sum()` 应返回这两个整数的和。

例如：

| `a` | `b` | `sum()` 的结果 |
|---:|---:|---:|
| 2 | 3 | 5 |
| -2 | 3 | 1 |
| 0 | 0 | 0 |

测试数据保证结果处于 `int` 的可表示范围内。

## 测评流程

1. 测评系统取得提交版本中 `problems/T0_ab/` 的题目源码。
2. 测评系统使用自己的 CMake 配置，编译本题 `src/` 下的全部 `.cpp` 文件，并与测评程序链接。题目自带的 `CMakeLists.txt` 不参与正式测评。
3. 测评程序包含 `ab.hpp`，用测试数据构造 `Solver` 对象，再调用 `sum()`。
4. 测评程序将返回值与预期的 `a + b` 比较，根据测试结果计算分数。

测评程序只通过公开接口调用题目代码，不依赖 `Solver` 的内部实现。编译或链接失败时，本题无法进入测试用例评测。

## 接口约束

类名、公开函数的名称、参数和返回类型必须与 `include/ab.hpp` 保持一致。新增实现文件应放在本题的 `src/` 目录下，确保正式测评时能够被编译。
